# VM Comparison South Africa

What is the cheapest VM you can get that is based in South African data centers?

This is a lightweight web project that scours the internet for South African VPS VM deals so one can acquire the most resources for the lowest cash - bang for buck.
It should be updated every week by acquiring the data from the given websites and providers.
An email should be available for people to request to be shown.

The website should be very simple show a table of the cheapest options in each category - 1GB, 2GB, 4GB, 8GB etc.
There also should be the abilty of the user to select vCPU count and RAM (and maybe storage) to dynamically update what is shown.

The historic prves should also be stored per provider.
